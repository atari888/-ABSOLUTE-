ABSOLUTE — косметический ПвП-мод для Minecraft 1.21.4 (Fabric)
==============================================================

Только визуал, никаких читов. Мод работает только на клиенте и не даёт игрового
преимущества: нет reach, killaura, автокликера, ESP и т.п. Размеры хитбоксов и
перезарядка атаки не меняются.


УСТАНОВКА
---------
1. Нужны Minecraft 1.21.4 и Fabric Loader 0.16 или новее.
   В TLauncher выбери версию «Fabric 1.21.4».
2. Скачай Fabric API для 1.21.4: https://modrinth.com/mod/fabric-api
3. Положи Absolute-1.0.0.jar и Fabric API в папку mods:
   %APPDATA%\.minecraft\mods
4. Запусти игру.

Совместим с Sodium и Iris. Если в Iris включён шейдерпак, небо рисует шейдер,
и кастомное небо мода отключается само.


ГОРЯЧИЕ КЛАВИШИ И УПРАВЛЕНИЕ
----------------------------
Right Shift ................ открыть / закрыть меню
                             (переназначается: Настройки → Управление → Absolute)
ЛКМ по модулю .............. включить / выключить
ПКМ по модулю (или «›») .... открыть настройки модуля
Esc ........................ назад из настроек / закрыть меню
Печать текста в меню ....... поиск модулей
Тянуть за аватарку ......... двигать меню (ПКМ по аватарке — вернуть в центр)
F3 + B ..................... показать хитбоксы (стиль задаёт модуль Hitboxes)

Язык меню переключается в левом нижнем углу: RU / EN / 中文.


МОДУЛИ
------

[Главная]
  Описание возможностей мода, карточки всех модулей и счётчик включённых.

[ViewModel] — категория «Рендер»
  - Смещение по X/Y/Z, масштаб и поворот предмета в руке,
    отдельно для правой и левой руки.
  - Скорость анимации удара (только анимация, на скорость атаки не влияет).

[Hitboxes] — категория «Рендер»
  Работает, когда хитбоксы включены через F3+B.
  - На ком показывать: игроки, ты сам (F5), враждебные мобы, мирные мобы
    и животные, предметы и опыт, прочее.
  - Цвета по типам, толщина линий, полупрозрачная заливка,
    линия глаз, вектор взгляда.

[Potion HUD] — категория «HUD»
  - Список активных эффектов: иконка, название с уровнем, таймер.
  - Мигает, когда до конца эффекта меньше 5 секунд.
  - Кнопка «Переместить» открывает редактор HUD: перетаскивание мышью,
    колесо меняет масштаб, панель примагничивается к краям и центру.
  - Можно скрыть ванильные иконки эффектов в правом верхнем углу.

[Custom Sky] — категория «Мир» (только верхний мир)
  - Скайбокс: бесшовное ночное небо высокого качества (6 граней по 2048 px).
  - Градиент: два цвета и мерцающие звёзды.
  - Своя картинка: положи sky.png или sky.jpg в папку config\pvpvisuals\.
    Кнопка «Открыть» в меню открывает эту папку, «Обновить» перечитывает файл
    без перезапуска. Лучше всего подходит панорама 2:1 (equirectangular).
    Настраиваются масштаб, сдвиг, поворот и яркость.
  - Скорость вращения, ванильные солнце/луна/звёзды, туман в цвет неба,
    плавный горизонт.

[Misc] — категория «Разное»
  - Низкий огонь (высота настраивается).
  - Без тряски камеры при уроне.
  - Свой цвет нитки (tripwire), можно только для натянутой между крючками.
  - Свой прицел: цвет с прозрачностью, длина, толщина, зазор, точка, обводка.
    Рядом с меню появляется окно предпросмотра (перетаскивается),
    приближение 1x / 2x / 3x / 5x и разные фоны.


НАСТРОЙКИ
---------
Все настройки хранятся в файле config\absolutepvp.json, применяются сразу
и сохраняются автоматически. Чтобы сбросить всё, удали этот файл.
Если остался файл от старой версии (config\pvpvisuals.json),
он переименуется автоматически.
